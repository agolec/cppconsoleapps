3. What is a flag and how does it work?
	
		A flag is a condition that is meant to allow a specific action to occur in
		your code when encountered. It is made up of integers or booleans.

		Ex: you are parsing a number from a string, you'll use a flag to allow
		your code to loop until you've successfully entered a string that can
		be parsed into a number.

4. Can an if statement test expressions other than relational expressions? Explain.

		Yes. It can check whether a boolean is a specific value, which is not relating
		it to another variable. Statements can also be conditional and execute based
		on the value of an integer by itself, 0 being false, and just about anything 
		other than 0 being true.

5. Briefly describe how the && operator works.

		The && operator combines two expressions together for evaluation. Both expressions combined 
		must be true for the condition to be considered or evaluated to TRUE.

6. Briefly describe how the || operator works.
	
		The || operator is the OR operator. It evaluates two expressions, and in order to be true,
		at least one expression must be true; if each expression is false, then the entire 
		condition will be false.

7. Why are the relational operators called relational?

		They're called relational because they compare different values to one another. They
		test and define the logical relationship between two operands
